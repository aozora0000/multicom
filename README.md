# YouTubeコメントを複数窓で見るやつ

複数のYouTubeライブチャットを、指定したレイアウトで同時に表示するための小さなWebツールです。

## 使い方

1. アイコン付きの `レイアウト` メニューから表示形式を選びます。
2. `編集` を押します。
3. 各枠の入力欄にYouTubeの動画IDまたはURLを入力し、`更新` を押します。
4. 認識できたURLは、入力欄上では動画IDだけに変換されます。

対応URL例:

- YouTube動画ID
- `https://www.youtube.com/watch?v=...`
- `https://youtu.be/...`
- `https://www.youtube.com/embed/...`
- `https://www.youtube.com/shorts/...`
- `https://www.youtube.com/live/...`

YouTubeのコメントポップアップURLの仕様上、基本的に現在ライブ中の配信だけコメントを表示できます。通常動画や終了済み配信では表示されないことがあります。

## レイアウト

対応レイアウト:

- `2x1`
- `3x1`
- `4x1`
- `2x2`
- `2x3`
- `3x2`
- `4x2`
- `1x2`
- `1x3`
- `1x4`

レイアウトは後から変更できます。メニューには枠の並びを示すアイコンが表示されます。変更時はブラウザのURLも共有用に更新されます。

## 枠内で編集

`編集` を押すと、各枠の上に半透明の編集レイヤーが出て、枠の下部に入力欄と `更新` ボタンが出ます。

その枠へ直接YouTube URLまたは動画IDを入れて `更新` を押すと、該当枠にコメントを読み込みます。

入力欄を空にして `更新` を押すと、その枠を未設定にできます。

## D&Dで入れ替え

`編集` 中に表示枠そのものをドラッグ&ドロップすると、表示枠の位置を入れ替えられます。

D&D後もブラウザのURLは現在の配置に合わせて更新されます。

## 共有URL

ステータス行の `共有URL` をクリックすると、現在のレイアウトと入力値を含むURLをコピーできます。

URLは `?l=2x2&w1=...&w2=...` のようなクエリパラメータで状態を表します。レイアウト変更、D&D、枠内の更新でURLバーも更新されます。

## 外部ツールで開く

`外部レイアウト` を選ぶと、現在入力している動画IDを `https://vtuber.neocities.org/#/l-{レイアウトID}/{index}:{ID},...` 形式にして、`動画を開く` から「YouTubeを複数窓でみるやつ」へ移動できます。

このリンク生成は移動用の補助機能です。このアプリはリンク先サイトとは無関係で、リンク先の動作や仕様変更はこのアプリでは管理していません。

## 操作欄

`操作欄を隠す` を押すと、コメント表示領域を広く使えます。

画面上部の復帰ボタン、または `Esc` で操作欄を表示できます。

## 安全寄りの利用方針

このツールは、YouTubeのライブチャット画面をiframeで並べて表示するためのものです。YouTubeの規約や埋め込み制限を尊重して使ってください。

- 個人利用または非商用利用を前提にしてください。
- チャット内容の収集、保存、解析、再配布を目的に使わないでください。
- YouTube側でiframe表示が拒否された場合は、その制限を回避しないでください。
- 広告、課金、スポンサー表示など、YouTubeコンテンツを主目的にした収益化には使わないでください。
- YouTube APIを使う機能を追加する場合は、YouTube API Services Terms of Service を別途確認してください。

このREADMEは法的助言ではありません。公開・運用する場合は、最新のYouTube利用規約と関連ポリシーを確認してください。

## 開発

pnpmを使います。npmは使わないでください。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

リポジトリ設定で Pages の Source を `GitHub Actions` にしてください。
